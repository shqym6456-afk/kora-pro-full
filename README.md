# كورة برو (نسخة مسطّحة بدون مجلدات)

الملفات: `index.html` (الواجهة) و`server.js` (الخادم) و`teams.js` و`vercel.json` و`package.json`.

## مصدر البيانات
- **افتراضياً بدون أي مفتاح:** يقرأ الخادم من مشروع Free Football Live Scores API (المرفق `livescoreFootball`)، ويغطي الدوري الإنجليزي والإسباني، والسعودي ودوري الأبطال عند توفرهما لديهم. العنوان في المتغير `LIVESCORE_BASE` (الافتراضي `https://worldcup26.ir`). إن استضفت المشروع بنفسك ضع عنوانه هناك.
- **اختيارياً:** من ⚙️ الإعدادات داخل التطبيق يمكن لصق مفتاح API-Football أو football-data.org فيتحول إليه فوراً.
- المتغير `MOCK=1` يشغّل الوضع التجريبي، ولا يعمل إلا إن طلبته.

## النشر على Vercel
1. ارفع الملفات إلى مستودع GitHub جديد (Choose your files، لا مجلدات).
2. Vercel: Add New ← Project ← المستودع ← Framework: **Other** ← Deploy. لا تحتاج أي متغيرات.
3. افتح `رابطك/api/healthz` فيظهر `"provider":"livescore"`.
4. **مهم للمسابقة والاشتراكات:** أنشئ من Storage قاعدة **Upstash Redis** (مجانية) واربطها بالمشروع، وإلا تضيع النقاط والاشتراكات عند إعادة تشغيل الخادم.

## الاشتراك الشهري «كورة برو بلس»
- اختياري، والسعر المعروض من المتغير `PRICE_TEXT` (الافتراضي «1 دولار شهرياً»).
- المزايا: حتى 5 فرق مفضلة بتنبيهات وأصوات أهدافها، إحصائيات المباراة التفصيلية، أصوات تنبيه إضافية، تصدير مباريات فرقك إلى تقويم الهاتف، وشارة 👑 في المسابقة.
- **الدفع لا يتم تلقائياً.** يعتمد على أكواد تفعيل:
  1. عيّن `ADMIN_KEY` (كلمة سر طويلة).
  2. ولّد أكواداً: افتح `رابطك/api/codes?key=ADMIN_KEY&n=5&days=30`.
  3. المستخدم يدفع لك بالطريقة التي تناسبك (زين كاش، فيزا، رابط دفع...) وتعطيه كوداً، فيكتبه في ⚙️ ← «كورة برو بلس» ← تفعيل.
  4. لمنح اشتراك مباشر: `رابطك/api/grant?key=ADMIN_KEY&uid=معرّف&days=30`.
- `PAY_URL`: رابط صفحة دفع (مثل Stripe Payment Link) يظهر كزر «اشترك الآن».
- كود جائزة الفائز الأسبوعي في المسابقة (`KORA-...`) يُفعَّل أيضاً كاشتراك شهر مجاني.
- ملاحظة: قفل المزايا في الواجهة، وهو مناسب لتطبيق صغير، لكنه ليس حماية مصرفية.
